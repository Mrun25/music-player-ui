# Music Player UI

A music player interface: splash and login screens, home, search, library, album and artist pages, a full player with a mini player and visualizer, plus settings. UI project built as a design exercise.

## Stack

Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run lint    # eslint
```
